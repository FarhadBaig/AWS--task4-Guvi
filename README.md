# AWS--task4-Guvi# AWS Task-4 – EC2 and EBS

## Objective

Launch Linux and Windows EC2 instances with web servers,
create and attach 5 GB EBS volumes, create snapshots,
and restore new EBS volumes from the snapshots.

## Technologies Used

- AWS EC2
- AWS EBS
- Apache Web Server
- IIS Web Server

## Implementation

### 1. Linux EC2
- Launched Ubuntu EC2 instance
- Installed Apache web server
- Verified website using public IP
- Created 5 GB EBS volume
- Attached and mounted EBS volume
- Created test data
- Created EBS snapshot
- Created new EBS volume from snapshot

### 2. Windows EC2
- Launched Windows EC2 instance
- Installed IIS web server
- Verified website using public IP
- Created 5 GB EBS volume
- Attached and initialized EBS volume
- Created test data
- Created EBS snapshot
- Created new EBS volume from snapshot
